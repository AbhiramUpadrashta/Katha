# Katha — by Bubbles

Comics you can read **and** hear, in **English, Hindi and Telugu**: Ramayana, Mahabharata, Gajendra Moksham, Tenali Ramakrishna (6 stories), Akbar–Birbal (5 stories), Vikram–Betaal, Panchatantra, Greek and Egyptian myths — retold and drawn as original comics.

- **Web app:** https://bubbles.foo.ng/Katha/app/
- **Android:** [Katha.apk](https://github.com/AbhiramUpadrashta/Katha/releases/latest/download/Katha.apk)
- **Website:** https://bubbles.foo.ng/Katha/

Switch language any time, read panel by panel or as a strip, or tap Listen for narration with word highlighting (Android uses the phone's own Hindi and Telugu voices). Search works across all three languages. Check for updates is in Settings.

To release a new version: change `release.txt` (e.g. `1.0.1`) and push — the Android APK builds and the website updates automatically.

Stories come from public-domain epics, folk tales and myths. Text and artwork © 2026 Bubbles Aro, MIT License.
